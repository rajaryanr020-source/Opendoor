# HTML Project

This project is a simple web application for Serenity Spa, designed to provide information and facilitate contact with potential clients.

## Project Structure

- `index.html`: Contains the main HTML structure of the web application, including sections for content, a footer, and links to CSS and JavaScript files.
- `css/styles.css`: Intended for styling the HTML elements in the project. It contains CSS rules to enhance the visual presentation of the web application.
- `js/main.js`: Contains JavaScript functionality to add interactivity and dynamic behavior to the web application.

## Setup Instructions

1. Clone the repository to your local machine using:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd html-project
   ```
3. Open `index.html` in your web browser to view the application.
